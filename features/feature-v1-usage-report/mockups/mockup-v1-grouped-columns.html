Throughput — recommended formula

output tok/s = total output_tokens ÷ summed per-request time, where per-request time runs from the preceding transcript entry to the last entry of that request, summed over main and subagent requests.

Measured on a real /feature-storm run: request time was 86% of active time — the other 14% is tool execution and file I/O, which the model does not spend generating. Same run: output/active gives 65.5 tok/s, this gives 76.0.

(output + cache_read) ÷ active gives 27,538 — cache_read is 420× the output on that run, so it swamps the numerator and the figure reports context re-reading, not generation speed.

Computed once across main + subagents, not per column: subagents run in parallel, so a per-column figure would read as a slowdown that never happened.
